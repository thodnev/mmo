# Core concepts

## Currency

There is no single universal game currency.

Instead, there are numerous largely needed, rare and hard-to-get
resources that serve this purpose. Players will figure out the economics themselves.

Plus, there are Rizzles (i.e. slang for "real").
All NPCs need them, but no one knows why.

Rizzles need to be turned to enrich them (on some kind of machine / related to crypto??)

Enriched Rizzles can be used by players (for what??), thus giving some clues about why NPCs need them this much.

Ticker name is **RZL**
