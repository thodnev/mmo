## Character class ideas

- Wonderer (one that creates wonders). Not to be confused with wAnderer.
  
  Official terms:
  - Wonder-worker. Boring.
  - Thaumaturge. Mysticall but unknown to wide audience.
    
    Thaumaturgy is the practical application of magic to effect change in the physical world.

  Alt-terms:
  - Enchanter

- Trickster [INS + LUK]. Combines Insanity with some Luck.
  
  Profits from having high Insanity stats.
  Counters some side-effects of it using passive (and active) skills.

  Other names (2nd class ??):
  - Loki
  - Joker / Jester / Droll / Montley
  - Juggler
  - Illusionist
